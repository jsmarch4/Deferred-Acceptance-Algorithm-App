# Gale–Shapley Deferred Acceptance Algorithm Visualizer

Interactive Shiny for Python web app implementing both the doctor-proposing and hospital-proposing Deferred Acceptance Algorithm.

## Features

- User-defined numbers of doctors and hospitals
- Custom preference profiles
- Hospital-specific capacities
- Unacceptable matches
- Step-by-step execution
- Full algorithm log

## Built With

- Python
- Shiny for Python
- Shinylive
- GitHub Pages

## Run Locally

```bash
pip install shiny shinylive
python -m shiny run --reload app.py
```
